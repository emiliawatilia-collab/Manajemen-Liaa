# 📱 Cara Install Aplikasi Apartemen sebagai PWA

## ✅ Apa itu PWA?

**Progressive Web App (PWA)** adalah teknologi yang membuat website bisa diinstall seperti aplikasi native di HP. Keuntungannya:

- 📲 Muncul sebagai icon aplikasi di home screen
- 🚀 Buka langsung tanpa masuk browser (Chrome/Safari)
- 💨 Lebih cepat dan terasa seperti aplikasi native
- 📴 Bisa diakses offline (data tersimpan di HP)
- 🔔 Bisa menerima notifikasi (jika diaktifkan)

---

## 📱 Cara Install di Android (Chrome)

### Metode 1: Popup Otomatis
1. Buka aplikasi di Chrome
2. Tunggu beberapa detik
3. Akan muncul **popup biru di bawah** dengan tombol "Install"
4. Klik **"Install"**
5. Aplikasi akan muncul di home screen

### Metode 2: Manual dari Menu
1. Buka aplikasi di Chrome
2. Klik **titik tiga (⋮)** di pojok kanan atas
3. Pilih **"Install app"** atau **"Add to Home screen"**
4. Klik **"Install"**
5. Aplikasi akan muncul di home screen

### Metode 3: Dari Address Bar
1. Buka aplikasi di Chrome
2. Lihat **icon download (⬇️)** di address bar
3. Klik icon tersebut
4. Klik **"Install"**
5. Aplikasi akan muncul di home screen

---

## 🍎 Cara Install di iPhone (Safari)

### Langkah-langkah:
1. Buka aplikasi di **Safari** (bukan Chrome!)
2. Klik tombol **Share (📤)** di bawah
3. Scroll ke bawah, pilih **"Add to Home Screen"**
4. Edit nama jika perlu (default: "Apartemen")
5. Klik **"Add"** di pojok kanan atas
6. Aplikasi akan muncul di home screen

**Catatan:** Di iPhone, PWA hanya bisa diinstall dari Safari, tidak bisa dari Chrome.

---

## 🖥️ Cara Install di Desktop (Chrome/Edge)

### Langkah-langkah:
1. Buka aplikasi di Chrome atau Edge
2. Lihat **icon install (⊕)** di address bar (pojok kanan)
3. Klik icon tersebut
4. Klik **"Install"**
5. Aplikasi akan terbuka di window terpisah
6. Shortcut akan muncul di desktop dan Start Menu

---

## ✅ Ciri-ciri Aplikasi Sudah Terinstall

Setelah install berhasil:

1. **Icon muncul di home screen** dengan nama "Apartemen"
2. **Buka tanpa browser** - langsung seperti aplikasi native
3. **Tidak ada address bar** - tampilan full screen
4. **Lebih cepat** - data di-cache di HP
5. **Bisa offline** - tetap bisa dibuka tanpa internet (data lokal)

---

## 🔧 Troubleshooting

### Popup Install Tidak Muncul?
- Pastikan menggunakan **HTTPS** (bukan HTTP)
- Coba refresh halaman (F5 atau pull down)
- Coba buka di **Incognito/Private mode** dulu
- Pastikan belum pernah dismiss popup sebelumnya

### Tidak Ada Menu "Install App"?
- Pastikan menggunakan **Chrome versi terbaru**
- Coba clear cache browser
- Pastikan manifest.json dan service worker sudah load

### Di iPhone Tidak Bisa Install?
- Pastikan menggunakan **Safari**, bukan Chrome
- Chrome di iPhone tidak support PWA install
- Gunakan metode "Add to Home Screen" dari Safari

### Aplikasi Tidak Update?
- Tutup aplikasi sepenuhnya
- Buka lagi, akan auto-update
- Atau uninstall dan install ulang

---

## 🗑️ Cara Uninstall

### Android:
1. Tekan dan tahan icon aplikasi
2. Pilih **"Uninstall"** atau **"Remove"**
3. Atau: Settings → Apps → Apartemen → Uninstall

### iPhone:
1. Tekan dan tahan icon aplikasi
2. Pilih **"Remove App"**
3. Pilih **"Delete App"**

### Desktop:
1. Klik kanan icon aplikasi
2. Pilih **"Uninstall"**
3. Atau: Settings → Apps → Apartemen → Uninstall

---

## 🎯 Tips Penggunaan

1. **Install di HP admin** untuk akses cepat
2. **Bookmark di browser** sebagai backup
3. **Data tersimpan lokal** di HP (localStorage)
4. **Tidak perlu internet** untuk buka aplikasi (data lokal)
5. **Update otomatis** saat buka aplikasi dengan internet

---

## 📞 Support

Jika ada masalah saat install, pastikan:
- ✅ Menggunakan browser modern (Chrome/Safari terbaru)
- ✅ Koneksi internet stabil saat pertama kali install
- ✅ Storage HP tidak penuh
- ✅ Menggunakan HTTPS (bukan HTTP)
